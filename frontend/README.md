# Siatara Hussain — PMP & Scrum Coaching Website

A modern portfolio and coaching website for **Siatara Hussain**, built with React, Vite, Tailwind CSS, and React Router.

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- React Router
- Lucide React icons

## Pages

- **Home** — Hero, Benefits, About, Services, Courses, Testimonials, CTA
- **Portfolio** — Training portfolio showcase
- **Contact** — Contact and booking forms

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
```

Output is generated in the `dist/` folder.

## Deploy to Vercel

| Setting | Value |
|---------|-------|
| Framework Preset | Vite |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm install` |

The included `vercel.json` handles React Router client-side routing.
